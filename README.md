# Персональный таск-менеджер

Этот репозиторий содержит простой консольный менеджер задач для проектов по дизайну в Figma и прототипированию.

## Использование

```bash
# добавить задачу
python task_manager.py add <проект> "Описание задачи"

# вывести список задач по проекту
python task_manager.py list <проект>

# отметить задачу выполненной (номер берем из вывода list)
python task_manager.py done <проект> <номер>
```

Все данные хранятся в файле `tasks.json` в корне репозитория.
